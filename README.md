# Kadr — свій CleanShot для macOS

Нативний додаток у рядку меню (Swift, ScreenCaptureKit). Без підписок, хмари й телеметрії. Потрібна macOS 15+.

## Що вміє

**Знімки**
- Область із «замороженим» екраном, лупою ×8, координатами й HEX-кольором пікселя; Shift — квадрат
- Вікно (клік по вікну або Пробіл у режимі області) — з тінню й прозорістю, навіть якщо його перекрито
- Весь екран (⏎ у режимі вибору), попередня область, таймер 3/5/10 с
- Скролінг-знімок: вибрав область, повільно скролиш, Kadr сам зшиває кадри
- OCR: текст з області в буфер (укр/англ/пол/нім), плюс вміст QR-кодів

**Після знімка** — панель швидкого доступу в куті: копіювати, зберегти, редагувати, закріпити, поділитися, у кошик, перетягнути файл просто в Telegram/Figma/Finder. Подвійний клік — у редактор.

**Редактор**: стрілка, лінія, прямокутник, заливка, еліпс, олівець, маркер, текст, нумерація кроків, пікселізація, розмиття, прожектор, обрізка. Фон із градієнтом, відступи, заокруглення й тінь — для гарних скрінів у соцмережі. Undo/redo, переміщення й зміна кольору вже намальованого, стрілки — зсув.
Клавіші: V A L R F O P H T N X B S C — інструменти, 1–8 — кольори, ⌫ — видалити, ⌘⏎ — готово (копіює й зберігає).

**Запис екрана**: одразу з'являється червона рамка на весь екран — тягни кути чи краї, щоб змінити розмір (Shift на куті — зберегти пропорції), всередині — перемістити, поза рамкою — намалювати нову, подвійний клік — знову весь екран. Поруч компактна панель підготовки. У ній живі індикатори рівня мікрофона й системного звуку (видно, чи пишеться звук, ще до старту), вибір мікрофона, вебкамера в кружечку, курсор, кліки, клавіші, сховати іконки, відлік 0/3/5/10 с, 30/60 fps і перемикач відео/GIF. Пишеться MP4 (H.264/HEVC) зі звуком; стоп — з рядка меню або тією ж клавішею. Під час запису на панелі є пауза, хвилька рівня мікрофона (рухається від того самого звуку, що йде у файл; помаранчева — мікрофон увімкнено, а сигналу нема) і кнопка вимкнути/увімкнути мікрофон. Частини між паузами Kadr склеює в один файл без перекодування. Після запису типово відкривається тека з файлом (у налаштуваннях можна вибрати панель швидкого доступу або відеоредактор). ⌘C в редакторі знімків копіює й закриває його.

**Відеоредактор** (з панелі швидкого доступу — ножиці або подвійний клік; або одразу після запису, якщо так вибрано в налаштуваннях): обрізка початку й кінця на таймлайні з кадрами (I/O — початок/кінець у позиції курсора, Пробіл — пуск), без звуку, швидкість 0.5–2×, якість (оригінал/1080p/720p), експорт у MP4 або GIF.

**Ще**: піни поверх усіх вікон (скрол — масштаб, правий клік — прозорість, блокування «клік крізь»), сховати іконки робочого столу, історія знімків, редагувати картинку з буфера, запуск при вході.

## Гарячі клавіші (змінюються в налаштуваннях)

| | |
|---|---|
| ⌥⇧1 | область |
| ⌥⇧2 | вікно |
| ⌥⇧3 | весь екран |
| ⌥⇧4 | попередня область |
| ⌥⇧5 | запис відео (старт/стоп) |
| ⌥⇧6 | запис GIF |
| ⌥⇧7 | OCR |
| ⌥⇧8 | скролінг-знімок |
| ⌥⇧P | закріпити з буфера |
| ⌥⇧H | історія |

Хочеш на ⌘⇧3/⌘⇧4 — спершу вимкни системні: Системні параметри → Клавіатура → Скорочення → Знімки екрана.

## Встановлення

Потрібна macOS 15+. Готова збірка — для Apple Silicon.

**Одна команда** (завантажить останній реліз, поставить у «Програми» й запустить):

```bash
curl -fsSL https://raw.githubusercontent.com/slavashootit/kadr/main/install.sh | bash
```

Або завантаж `Kadr.dmg` зі [сторінки релізів](https://github.com/slavashootit/kadr/releases/latest), перетягни в «Програми» й один раз зніми карантин: `xattr -cr /Applications/Kadr.app`.

**Зібрати самому** (потрібні Command Line Tools: `xcode-select --install`; працює і на Intel):

```bash
git clone https://github.com/slavashootit/kadr.git && cd kadr && ./build.sh install
```

Оновлення з коду: `git pull && ./build.sh install`.

Після першого запуску дай дозвіл: Системні параметри → Приватність і безпека → Запис екрана й аудіо системи → Kadr, потім перезапусти Kadr.

### Щоб дозвіл не злітав після кожного перезбирання

Ad-hoc підпис змінюється з кожною збіркою, і macOS знову питає дозвіл. Один раз створи власний сертифікат: «Доступ до звʼязки ключів» → Асистент сертифікації → Створити сертифікат → назва `Kadr Dev`, тип «Підпис коду». Далі:

```bash
KADR_SIGN_ID="Kadr Dev" ./build.sh install
```

## Чого поки немає

Хмарного аплоаду з короткими лінками (як CleanShot Cloud) і збірки для Intel (збирається з коду). Скролінг-знімок не впорається з «липкими» шапками сайтів, які повторюються в кожному кадрі.

## Версії

Поточна версія лежить у файлі `VERSION` (зараз 1.1.0). Випуск нової: змінити `VERSION`, зробити тег `vX.Y.Z` (`git tag v1.0.1 && git push --tags`), і GitHub сам збере та опублікує `Kadr.dmg` і `Kadr.zip`. Сторінка (`docs/`) викладається через GitHub Pages автоматично.
