Скріншоти й запис екрана без підписок

Kadr — це CleanShot X, який можна просто завантажити. Знімок області, вікна й скролінгу, запис відео та GIF зі звуком, редактор, OCR і закріплення знімків поверх вікон. Живе в рядку меню, нічого нікуди не вантажить.

⬇ Скачати для Mac Код на GitHub

Для Apple Silicon (M1 і новіші). На Intel — збірка з коду, див. «Встановлення».

Або одним рядком у Терміналі:

curl -fsSL https://raw.githubusercontent.com/slavashootit/kadr/main/install.sh | bash

Усе, що треба для скрінів

Платні можливості CleanShot X, зібрані в одну легку програму.

🎯

Область, вікно, екран

Екран «заморожується», є лупа ×8 з координатами та HEX-кольором. Вікно знімається з тінню, навіть якщо його перекрито.

📜

Скролінг-знімок

Виділив область, повільно скролиш — Kadr сам зшиває довгу сторінку в одну картинку.

🎬

Запис відео та GIF

MP4 (H.264 або HEVC, 30/60 fps) із системним звуком і мікрофоном. Підсвітка кліків, показ натиснутих клавіш, вебкамера в кружечку.

🎚️

Перевірка звуку до запису

Компактна панель із живими індикаторами рівня мікрофона й системного звуку. Видно, що звук пишеться, ще до старту.

✂️

Відеоредактор

Обрізка на таймлайні з кадрами, швидкість 0.5–2×, прибрати звук, якість, експорт у MP4 або GIF.

🖍️

Редактор знімків

Стрілки, фігури, текст, нумерація кроків, пікселізація, розмиття, прожектор, обрізка. Гарний фон із градієнтом і тінню для соцмереж.

🔤

OCR

Виділив текст на екрані — він у буфері. Українська, англійська, польська, німецька, плюс вміст QR-кодів.

📌

Піни поверх вікон

Закріпи знімок як референс: скрол — масштаб, правий клік — прозорість, режим «клік крізь».

⚡

Швидка панель

Після знімка в куті з'являється мініатюра: копіювати, зберегти, редагувати, поділитися, перетягнути файл у Telegram чи Figma.

🖥️

Чистий стіл

Одним ярликом ховає іконки робочого столу для охайних скрінів і записів.

🔒

Приватність

Нічого не йде в інтернет: ні аналітики, ні хмари, ні акаунтів. Усе лежить у теці на твоєму Маку.

⌨️

Встановлення

Потрібна macOS 15 (Sequoia) або новіша. Готова збірка — для Apple Silicon; на Intel збери з коду: ./build.sh install.

  1. Завантаж і перетягни в «Програми»Відкрий Kadr.dmg і перетягни Kadr на папку Applications.
  2. Перший запускПрограма не підписана Apple, тому macOS може не відкрити її. Зніми карантин одним рядком: xattr -cr /Applications/Kadr.app, потім відкрий Kadr. Або правий клік по програмі → «Відкрити».
  3. Дозвіл на запис екранаСистемні параметри → Приватність і безпека → Запис екрана й аудіо системи → увімкни Kadr і перезапусти його.
  4. КористуйсяІконка Kadr з'явиться в рядку меню. Натисни ⌥ ⇧ 1 і виділи область.

Питання

Чому macOS каже, що програму не можна відкрити?

Kadr безкоштовний і не має платного сертифіката розробника Apple, тож не нотаризований. Один раз виконай xattr -cr /Applications/Kadr.app або відкрий через правий клік → «Відкрити».

Після оновлення знову просить дозвіл на запис екрана

Це буває, коли програму збирають без постійного підпису. Вимкни й увімкни Kadr у Параметрах → Приватність і безпека → Запис екрана. Якщо збираєш сам, створи власний сертифікат підпису й задай KADR_SIGN_ID — інструкція в README.

Не працюють ⌘⇧3 і ⌘⇧4

Їх займає системний скріншотер. Вимкни його: Системні параметри → Клавіатура → Скорочення → Знімки екрана. Потім признач ці клавіші в налаштуваннях Kadr.

Де лежать знімки?

За замовчуванням у ~/Pictures/Kadr. Теку можна змінити в налаштуваннях.

Як зібрати самому?

Потрібні Command Line Tools (xcode-select --install). Далі git clone https://github.com/slavashootit/kadr.git && cd kadr && ./build.sh install.
